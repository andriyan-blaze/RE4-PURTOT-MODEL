# RE4-PURTOT-MODEL
Porting all models available on the internet to game RE4 (PS2, Wii, Ubisoft, UHD, PS3).
# Compatibility
- Blender v3.6.0 LTS / Portable (Already locked for this version).
# Fitur / Panel
- Import/load 3D models in .OBJ format (from your PC/laptop directory).
- Export 3D models in .OBJ format (select your PC/laptop directory to save the results).
- Load textures and auto-index each material for each mesh object in the Blender scene (to do this, click texture and select the mesh object).
- Split mesh, according to the maximum result setting, will limit the division according to the mesh, because in RE4 the mesh has a UV load limit. And the option to fill in the material that will be indexed to each mesh.
- Merge mesh, everything in the Blender scene, regardless of the number, will be merged into the topmost mesh.
- Smooth mesh, this function smooths each vertex/face of the object because the result of the merge is all separated almost irregularly.
- Fix mesh, serves to fix faces/polygons that usually cause transparency bugs after export, in this case the texture index is not transparent.
